# NickGenBot

Telegram-бот, що генерує ніки та юзернейми. .NET 8 + Telegram.Bot 21.11 (long polling).

## Запуск у Visual Studio

1. Створи бота в [@BotFather](https://t.me/BotFather) (`/newbot`) і скопіюй токен.
2. Відкрий `Properties/launchSettings.json` і заміни `PUT_YOUR_TOKEN_HERE` на свій токен.
3. Відкрий `NickGenBot.csproj` у VS, дочекайся відновлення NuGet, F5.

Токен береться зі змінної середовища `BOT_TOKEN`. Не коміть його (файл уже в `.gitignore`).

## Що вміє

- `/start` — меню з кнопками (ніки / юзернейми → вибір стилю → «Ще»).
- `/nick`, `/username` — одразу згенерувати набір.
- Надішли будь-яке слово (напр. своє імʼя, можна кирилицею) — отримаєш ніки з декором і
  юнікод-шрифтами та юзернейми з транслітерацією.
- Стилі: Крутий, Мілий, Геймерський, Темний, Аніме, Смішний, Будь-який.
- Юзернейми відповідають правилам Telegram: 5–32 символи, `a-z 0-9 _`, починаються з літери,
  не закінчуються на `_`, без `__`.

## Платні унікальні юзернейми (Telegram Stars)

- Унікальні = короткі (5–7 літер), вимовні, без цифр і `_`, і підтверджено вільні на момент пошуку.
- Купується набір із 5 імен за Stars (⭐). Ціни й пакети: `Shop.cs` (за замовчуванням 1 набір = 25⭐,
  5 наборів = 100⭐).
- Меню → «💎 Унікальні юзернейми», або `/shop`, `/balance`, `/paysupport`.
- Баланс і журнал покупок (з `charge id` для підтримки) лежать у `data/credits.json`
  (папку можна змінити змінною `DATA_DIR`). Файл у `.gitignore`.
- Якщо повний набір знайти не вдалось або стався збій, набір повертається на баланс.
- `/paysupport` обовʼязковий для ботів з оплатою. Контакт підтримки задай змінною `SUPPORT_CONTACT`
  (наприклад, `@your_username`) у `launchSettings.json`.
- Зірки накопичуються на балансі бота, виводяться власником через Fragment.

## Структура

- `Program.cs` — старт бота, команди, polling.
- `Handlers.cs` — повідомлення, кнопки, клавіатури.
- `NickGenerator.cs` — слова, шаблони, транслітерація, валідація.

## Нотатки

- Кожен юзернейм перевіряється на зайнятість (`UsernameChecker.cs`): спочатку Bot API `getChat`,
  потім сторінка `t.me/імʼя`. Позначки: ✅ вільний, ❌ зайнятий, ❔ не вдалося перевірити.
  Результати кешуються на 10 хвилин.
- Перевірка орієнтовна: зарезервовані, заблоковані чи продані на Fragment імена можуть
  показуватись як вільні. Остаточно підтверджується лише при створенні імені в Telegram.
- Словники — масиви в `NickGenerator.cs`, просто дописуй слова.
